# room-geometry-estimation
Code to the paper: Robust and Geometrically Consistent Room Geometry Estimation using Distance Measurements.

matlab contains matlab code to run the wall estimation. See example.m for a starting point. 
python contains python code used to generate the synthetic datasets.

# Dataset
Datasets used can be found from the project page: https://maltelarsson2.github.io/room-geometry-estimation/
